# Luiza Marinho — Portfólio

Portfólio pessoal em HTML, CSS e JavaScript puro.

## Seções
- **Sobre** — apresentação, formação e foto
- **Tecnologias** — linguagens, front-end, back-end, banco de dados e ferramentas com ícones
- **Projetos** — lista com prints reais, filtro por categoria e detalhes de cada projeto
- **Contato** — formulário com validação, cópia de e-mail e GitHub

## Funcionalidades
- Painel lateral fixo com navegação que acompanha a seção atual (no celular, barra de navegação inferior)
- Modo claro/escuro (respeita o sistema e lembra a escolha)
- Animações ao rolar e destaque de luz que acompanha o cursor
- Filtro de projetos com indicador deslizante e janela de detalhes
- Formulário com validação que abre o e-mail com a mensagem preenchida

## Deploy
Projeto estático: na Vercel, importe o repositório e publique sem configuração extra.
